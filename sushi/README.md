# 超神田壽司 真工夫對決

經營阿兩的壽司分店，跟憂鬱比營業額。店裡有小鋼珠和賽車機台。同人作品，非官方。

- 店家版本：10 關的關卡模式，加上可以一直玩下去的無限模式。
- 顧客版本：直接玩小鋼珠和賽車，有零用錢挑戰、壽司圖鑑、排行榜。
- 等角像素畫面。所有圖都用程式畫，所有聲音都用 Web Audio API 即時合成。沒有任何圖檔、音檔，也不從網路載入任何東西。
- 純靜態網頁：不需要安裝、不需要打包。

## 怎麼開

整個遊戲就是 `sushi/` 這個資料夾。

1. 進到 `sushi/` 資料夾。
2. 啟動一個靜態伺服器：

   ```bash
   python3 -m http.server 8080
   ```

   或用附的小伺服器（需要 Node.js 20 以上）：

   ```bash
   node tests/serve.mjs 8080
   ```

3. 用瀏覽器打開 `http://localhost:8080/`。

不能直接雙擊 `index.html`。瀏覽器不允許 `file://` 載入 JavaScript 模組。

### 單一檔案版

`dist/sushi.html` 是整個遊戲打包成的一個檔案（約 310 KB）。直接雙擊就能玩，不需要伺服器。也可以傳給別人或丟到任何靜態網站。

改過程式之後要重新產生：

```bash
npm i --no-save esbuild
node tools/build-single.mjs
```

`dist/sushi.html` 不會自動更新。開發和測試照樣用 `index.html`。

手機要轉橫向。直向時會顯示轉橫的提示。

## 怎麼玩

### 店家版本：關卡模式

一關是一個營業日。流程：開場對話 → 準備 → 營業 → 打烊結算 → 評星。

1. 準備階段：進貨、定菜單和價錢、排員工。時間不會走。
2. 按「開店」。時間開始走，客人進門。
3. 打烊時營業額要贏過憂鬱（第 1 關是固定目標）。
4. 過關才解鎖下一關。

| 星數 | 條件 |
|---|---|
| ★ | 過關 |
| ★★ | 營業額超過目標 15% 以上 |
| ★★★ | ★★，而且評價沒有下降、沒有被吃出魚目混珠 |

| 關 | 名稱 | 新要素 | 目標（¥） |
|---|---|---|---|
| 1 | 分店交給你了 | 教學：進貨、菜單、開店、調速度 | 12,000（固定） |
| 2 | 憂鬱回來了 | 定價、跟憂鬱比 | 45,000 |
| 3 | 日薪打工仔本田 | 員工、桌位、觀光客、部長 | 50,000 |
| 4 | 小鋼珠壽司開張 | 小鋼珠台、釘子設定、試玩 | 80,000 |
| 5 | 職業玩家來襲 | 強敵對策 | 85,000 |
| 6 | 賽車壽司開張 | 賽車機台、難度、試玩 | 105,000 |
| 7 | 修馬哈來了 | 賽車強敵 | 115,000 |
| 8 | 中川水產的高級魚 | 三種賣法、均一價招牌、美食家 | 130,000 |
| 9 | 神之舌 | 檸檬試吃 | 140,000 |
| 10 | 真工夫對決 | 全部要素 | 165,000 |

第 10 關有 4 種結局：沒過關、過關但被吃出來（平手）、過關（沒作弊、沒三星）、三星。

### 店家版本：無限模式

長期經營。一天一天過，有日曆、租金、薪水、每日魚價。

- 擺設、移動、賣出家具。擴建店面（最大 20×16）。往上加蓋樓層（一般樓層或包廂樓層）。
- 雇用和解雇員工，訓練員工。
- 用「靈感點」研發新菜單、新家具、第 2 種小鋼珠機種、新賽道。
- 夏春都的任務、每月跟憂鬱比營業額、隨機事件。
- 可以跟中川借錢。資金一直是負的就會破產。
- 開店前和打烊後自動存檔。營業中不存檔：營業中離開，回來時從當天的準備階段開始。
- 設定畫面可以匯出、匯入存檔（JSON 檔）。

### 小鋼珠

店裡的小鋼珠台是數位機（デジパチ），照日本現在最常見的機台做。付一次入場費借 125 顆鋼珠（一顆 ¥4）。

1. 左打：力道調在綠色的「左打」區。鋼珠進中間下面的「ヘソ」（始），螢幕的三個數字轉一次。
2. 三個數字一樣就是大當。力道拉到「右打」（預設會自動切換），鋼珠繞到右邊，進打開的アタッカー。
3. 大當後是確變。繼續右打，鋼珠進電チュー，數字一直轉，很容易再中。
4. 借的 125 顆打完、機台回到普通，這一局就結束。贏到的鋼珠（出玉）換成壽司：特上拼盤 895 顆、T4 188 顆、T3 113 顆、T2 61 顆、T1 27 顆。從貴的換起，零頭有 14 顆以上算一貫 T1。

| 機種 | 大當機率（釘子設定 1 到 5） | 大當 | 確變 |
|---|---|---|---|
| 龍神傳 | 1/88、1/65、1/44、1/33、1/27 | 2 或 6 回合，一回合進 8 顆、一顆賠 10 顆 | 3 回，1/7 |
| 海鳴物語（研發後解鎖） | 1/50、1/36、1/25、1/19、1/16 | 2 或 4 回合，一回合進 6 顆、一顆賠 10 顆 | 2 回，1/5 |

ヘソ一顆賠 1 顆，左下的一般入賞口一顆賠 3 顆。釘子設定改兩件事：命釘（ヘソ正上方兩根釘子）的間距，和大當機率。

訣竅：

1. 力道 40 左右最好。鋼珠滾進螢幕左邊的「ワープ」會到螢幕下面的舞台，從舞台正中間掉下來幾乎一定進ヘソ。
2. 設定 3、力道對的話，大約四局有一局大當。
3. 按「名稱」會在盤面上標出各部位的名字。按「×1」可以切換 2 倍、4 倍速。

### 賽車

一場 6 台車、3 圈。玩家開小黃瓜捲車，從最後一位起跑。

- 對手是 5 台壽司車，越貴的越快：玉子、鮭魚、鮪魚赤身、鮭魚卵軍艦、黑鮪魚大腹。
- 過終點時，排在你後面的每一台壽司車，各給你一貫那一款壽司。一台都沒贏過，安慰獎是小黃瓜捲一貫。
- 比賽中超過一台，畫面上方那一款的圖示點亮；被追回去就變暗。只有過終點時的狀態算數。
- 山葵噴射每場 3 次。路上有醬油水灘（打滑）和山葵加速板（免費噴射）。

### 顧客版本

選一位角色（中川、麗子、本田、寺井、部長、纏）。外觀不同，賽車數值有 ±5% 的差別。

- 自由遊玩：不花錢。小鋼珠選機種和釘子（緊、普通、鬆）；賽車選賽道和對手（難度 1 到 5，或修馬哈）。記錄每種組合的最佳成績。
- 零用錢挑戰：拿 ¥5,000 零用錢。小鋼珠 ¥500 一次、賽車 ¥800 一次。分數是贏到的壽司總價值；賽車還要乘上壽司完整度。前 10 名記在排行榜。
- 壽司圖鑑：12 種壽司加 3 種套餐。贏到過就點亮。
- 排行榜：零用錢挑戰的前 10 名。

## 規則摘要

### 經營

- 客人進門找座位。沒有座位就排隊（最多 5 組），隊伍滿了就走掉。
- 客人一貫一貫點。點餐看偏好、價錢、品質。太貴不點；想吃的賣完了會不高興。
- 師傅捏好之後：座位離任何一座板前檯 2 格以內就直接遞；再遠就由外場員工送；沒有外場員工，師傅自己送（這時不能捏壽司）。
- 耐心只在排隊和等餐時倒數。等太久會生氣離開，評價下降。
- 滿意度 85 以上給小費（消費的 5%）。滿意度 75 以上，真工夫量表增加。量表滿了可以發動真工夫：30 分鐘內捏得快一倍、技術更好。
- 庫存上限 200 單位，冰箱一台加 150。營業中進貨是緊急補貨：貴 50%，20 遊戲分鐘後才到。

### 強敵與事件

| 角色 | 會做什麼 | 你的對策 |
|---|---|---|
| 大原部長 | 阿兩在板前檯沒有變裝，5 分鐘後被認出來：罰 ¥10,000，阿兩被拖走 60 分鐘 | 部長來時按「變裝」（捏得慢 30%），走了記得解除 |
| 小鋼珠職業玩家 | 連玩 12 次，把高級壽司打光 | 放任、調緊釘子（那台變設定 1，再玩 2 次就走）、親自應戰（贏他的成績：他付 ¥5,000、評價 +2；輸：他拿走雙倍獎品） |
| 修馬哈 | 連跑 8 場，幾乎全拿 | 放任、調高難度（變難度 5，再跑 2 場就走）、親自應戰（跑在他前面：他付 ¥10,000、評價 +3；輸：5 款壽司各拿 2 貫） |
| 檸檬 | 試吃 3 個品項，一定吃得出魚目混珠。來之前 30 分鐘有預告 | 預告後把菜單改回誠實的賣法 |

### 機台

- 小鋼珠台的「釘子」1 最緊、5 最鬆。賽車機台的「難度」1 最簡單、5 最難。
- 越鬆（越簡單）客人越常贏，口碑越好，來玩的人越多，但送出去的壽司也越多。
- 獎品要由師傅做，會扣庫存，不收錢。
- 開店前可以按「試玩」親手玩一局。試玩不收錢，也不影響店裡。

## 計劃書沒寫、自己決定的規則

### 經營

1. 外場員工一趟最多拿 8 貫（`TRAY_SIZE`）。外場忙的時候，壽司先放在檯面上等他回來拿。每位外場待送超過 12 貫（`FLOOR_BACKLOG`）才由師傅自己送。
2. 耐心是「單次等待」的上限：每次等餐、每次排隊都重新倒數。
3. 吃一貫 3 遊戲分鐘。
4. 排隊排到生氣離開，整組只扣一次評價（−0.2）。
5. 打烊時還在店裡的客人就地結帳。沒點餐就離開的客人不影響評價。

### 機台

1. 小鋼珠力道太弱時鋼珠射不上去，掉回來退還，不扣球。
2. 一般客進門時也可能去玩機台：機率是 15%（觀光客 10%）乘上那台機台的「玩的機率」。這樣的客人只玩 1 次，不點餐。
3. 愛好者第 1 次一定玩；之後每次用「玩的機率」決定要不要再玩。
4. 獎品發不出來（食材全部沒貨）時，一次遊玩只發一張招待券、扣一次評價。每貫都扣的話，一次大獎就扣 8 分，太重。
5. 客人在機台前吃獎品：每貫 2 分鐘，最多 10 分鐘。沒做完的獎品打包帶走：訂單取消，但食材不退回。
6. 職業玩家挑釘子最鬆的台；修馬哈挑難度最低的機台。
7. 職業玩家的目標成績可能是 ¥0（出玉不到 14 顆，換不到壽司）。這時你只要換到任何東西就算贏。
8. 親自應戰中途離開：小鋼珠用目前的出玉結算，沒打完的借球不算；賽車算輸。
10. 小鋼珠的一局在借球打完、機台回到普通時結束。確變中出玉用完就提早結束，剩下的保留不轉。
11. 確變中ヘソ的保留不轉，等確變結束再用普通機率轉（電チュー的保留先轉，和真機一樣）。
9. 入場費一次調 ¥100。

### 顧客版本

1. 自由遊玩的釘子「緊、普通、鬆」是設定 1、3、5。對手選修馬哈時，其他壽司車用難度 5。
2. 零用錢挑戰：賽道可以選，難度固定 3、釘子固定 3、機種固定「龍神傳」。中途離開賽車，那一場算 0 分（入場費照扣）。錢少於最便宜的入場費就自動結束。至少玩過一次才記進排行榜。
3. 圖鑑：出玉換到的只有等級，所以從那個等級隨機選一款壽司點亮。套餐的拿法：出玉換到特上拼盤；小鋼珠一局換到 5 貫以上（不算特上拼盤）是並套餐；賽車一場贏過全部 5 台是上套餐。
4. 排行榜分數一樣時，先拿到的排前面。

### 其他

1. 第 10 關多一種結局「過關」（沒作弊、沒三星）。計劃書只寫了三種。
2. 經營畫面的音樂：營業中、而且那個小時的來客倍率 ≥ 1.4（12 時、18 時、19 時）時換成尖峰時段的版本。

### 平衡報告

`node tools/sim-levels.mjs` 用兩個自動玩家各跑每關 20 個種子。`naive` 照建議量進貨、營業中什麼都不做；`good` 照一套合理的策略玩。要求（計劃書 11.5）：

- `naive` 第 1 關過關率 ≥ 80%，第 3 到 10 關 ≤ 30%。
- `good` 全部 10 關過關率 ≥ 90%，拿到 ★★ 的比例 ≥ 50%。

目前的結果：`naive` 第 1 關 100%、第 2 到 10 關 0%；`good` 全部 100%，★★ 70% 到 100%。

## 聲音

全部用 Web Audio API 合成，沒有音檔。瀏覽器要求使用者互動後才能出聲，所以第一次點畫面或按鍵時才開始。

- 音樂：6 首原創的晶片音樂，每首 8 小節循環（`src/data/music.js`，播放器在 `src/core/music.js`）。標題、經營（平常）、經營（尖峰時段）、小鋼珠、賽車、結算。對話、暫停、強敵選單不換音樂。
- 音效：按鈕、收銀、進門、生氣、壽司完成、真工夫、警告橫幅、部長怒吼、小鋼珠發射、撞釘子、入賞、ワープ、聽牌、開門、大當、賽車引擎（音高跟速度連動）、噴射、碰撞、水灘、倒數、出發、過關、失敗。
- 音量在設定畫面調。分頁切到背景時，音樂和模擬都會暫停。

`data/`、`sim/`、`mini/*/physics.js`、`mini/*/ai.js`、`core/rng.js` 不用 `window`、`document`、`Date`、`Math.random`。所有隨機都來自有種子的亂數，遊戲狀態是純 JSON，所以存檔就是 `JSON.stringify`，同一個種子跑兩次結果完全一樣。

## 測試

需要 Node.js 20 以上。端對端測試用 Playwright 和 Chromium（`tests/pw.mjs` 會找環境裡已經裝好的）。

1. 單元測試（126 項，大約 30 秒）：

   ```bash
   npm test
   ```

2. 端對端測試（11 個檔案，大約 10 分鐘）：

   ```bash
   npm run e2e
   ```

   只跑其中一個：

   ```bash
   node tests/run-e2e.mjs pachinko
   ```

3. 平衡報告（大約 5 秒）：

   ```bash
   node tools/sim-levels.mjs
   ```

| 端對端測試 | 內容 |
|---|---|
| `smoke` | 兩種尺寸載入標題、主選單、各個子畫面可以返回 |
| `portrait` | 手機直向顯示轉橫提示 |
| `level` | 用介面進貨、開店、快轉到打烊、看到結算和星數 |
| `level-bot` | 第 5、7、10 關讓 `good` 跑完，事件橫幅和結算正確 |
| `pachinko` | 鍵盤調力道、空白鍵連發、強制大當看右打、打完 125 顆的結算、設施分頁、試玩、職業玩家選單 |
| `race` | 鍵盤開車、自動駕駛跑完、HUD 壽司圖示、結果畫面；經營畫面的賽車機台和修馬哈 |
| `endless` | 新遊戲、擺設、雇人、開店、結算、存檔、重新載入、樓層 |
| `customer` | 選角色、零用錢挑戰、圖鑑、排行榜、自由遊玩 |
| `gallery` | 圖鑑頁列出全部像素圖 |
| `perf` | 20×16 的店、60 位以上的客人、4 倍速，一層樓和三層樓，平均每個畫面低於 10 毫秒；首次載入低於 2 秒；原始碼低於 1.5 MB |
| `screens` | 每個主要畫面在桌機和手機各截一張 2 倍圖；手機上每個按鈕至少 40×40 |

### 除錯用的網址參數

只在加了 `?debug=1` 時有效（`seed` 除外）。

| 參數 | 作用 |
|---|---|
| `seed=123` | 固定亂數種子 |
| `scene=level:3` | 直接進第 3 關。也可以用 `levels`、`endless`、`endless:new`、`endless:continue`、`customer`、`pachinko`、`pachinko:umi`、`race:wasabi`、`demo` |
| `speed=16` | 模擬加速 |
| `nointro=1` | 跳過開場對話 |
| `nohints=1` | 不顯示提示框 |
| `unlock=1` | 解鎖全部關卡 |

`window.__sushi` 提供 `state()`、`scene()`、`step(ticks)`、`act(action)`、`useBot(name)`、`mini()`。

## 已知的限制

1. 平衡是用自動玩家調的。親手玩的手感（尤其小鋼珠的力道和賽車的難度）還需要真人試玩。
2. 音樂是 8 小節的短循環，聽久了會重複。
3. 存檔只在這台電腦的瀏覽器裡。無痕模式下關掉就不見了（遊戲會提示一次）。
4. 不支援手把，也不支援直向的手機畫面。
