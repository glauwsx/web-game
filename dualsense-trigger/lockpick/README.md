# 開鎖師

靠 DualSense 手把的手感開鎖的遊戲。鎖針的位置畫面上看不到，只能用扳機摸出來。

- 網址：https://glauwsx.github.io/web-game/dualsense-trigger/lockpick/
- 需要：PS5 DualSense 手把、電腦版 Chrome 或 Edge（WebHID）
- 舊網址 `/web-game/lockpick/` 會自動轉到新位置

## 目前的關卡

| 關卡 | 內容 |
|---|---|
| 第一關：練習鎖 | 3 根鎖針，沒有時間限制。失誤 2 次後，燈條會提示正確位置 |
| 第二關：金庫 | 4 根鎖針，限時 90 秒。心跳隨時間加快，時間到被警察發現並開槍 |

### 核心機制（已完成）

1. 按住 L2 施加扭力，要保持在綠色範圍。太輕：鎖針會掉。太重：R2 整段變硬（卡死）。
2. 慢慢壓 R2。扳機變硬的區段就是鎖針的位置（扳機段落模式 Weapon）。
3. 停在變硬的地方按 ✕，鎖針就到位。壓過頭會「喀」一聲，代表失誤。
4. 全部鎖針到位後，轉動手把約 55 度（加速度計）把鎖轉開。

### 第二關的情境設計（已完成）

- 主角是潛入金庫的鎖匠。必須在警衛巡邏到之前開完鎖。
- 心跳：70 BPM 漸漸加到 170 BPM。每一拍有左馬達震動、心跳聲、燈條閃紅。失誤時心跳突然加速。
- 心跳的震動會干擾玩家感覺 R2 的阻力，所以時間越少越難開。
- 剩 15 秒：腳步聲、手電筒光掃過畫面。
- 時間到：「不許動！」、紅藍警燈、兩聲槍響（兩顆馬達最大震動、畫面閃白搖晃）、任務失敗。

## 想法清單（還沒做）

### 想法 1：記住按鍵的訊號

玩家提出的想法：

- 開始之前，玩家要記住 □ ○ △ ✕ 四個鍵各自對應的震動或燈號。
- 開鎖過程中，有一個步驟會出現某個震動或燈號。玩家要按下對應的按鍵。

可行性筆記（Claude 的看法）：

- 可以做。震動馬達、燈條、按鍵都已經在測試頁驗證過。
- 每局的對應最好隨機，記憶才有意義。
- 訊號要容易分辨。建議用「節奏」區分，例如短短、長、短長短、三連震。左右馬達的手感不同，也可以拿來區分。
- 燈條顏色最容易分辨，可以當成簡單難度。只用震動當成困難難度。
- 和心跳結合：心跳的震動會蓋過訊號，玩家要在心跳之間分辨訊號。這會很有壓迫感，但要先實測，避免變成完全分不出來。

### 想法 2：觸控板＋陀螺儀的轉盤鎖（還在構思）

玩家提出的想法：

- 用觸控板開鎖：兩根手指放在觸控板上一起旋轉。
- 搭配陀螺儀：例如先把手把轉 50 度，再用觸控板反向旋轉 120 度。

可行性筆記（Claude 的看法）：

- 兩指旋轉的角度可以算：觸控板會回報兩根手指的座標，用兩點連線的角度變化就能算出旋轉量。
- 手把旋轉的角度可以用陀螺儀累加，或用加速度計量傾斜角（第一關轉開鎖已經用了加速度計）。
- 要注意：觸控板很小（大約 5 公分寬）。兩根手指一次可能轉不到 120 度。可以讓玩家「轉一段、放開、再轉一段」累加，像轉保險箱轉盤一樣。
- 另一個選擇：一根手指在觸控板上畫圓圈（像轉盤）。這比兩指旋轉容易操作，可以實測後比較。
- 每轉 10 度給一下輕震，模擬轉盤的「格」。轉到正確角度時給不同的震動或聲音。
